Nearby

Solution de fidélité mobile pour les PME —
feed, jeux et parcours 100% personnalisable.

Le projet

Nearby offre aux PME une solution clé en main pour fidéliser leurs clients : un feed d'actualités, des jeux interactifs et un parcours de fidélité entièrement customisable.

Les commerçants créent leur propre expérience de marque depuis un back-office dédié, pendant que leurs clients interagissent via l'application mobile. Du concept jusqu'au déploiement en production, ce projet a été mené entièrement seul.

100%Solo
2025Année
iOS & AndroidPlateformes
Le problème
"Les PME n'ont pas les moyens de se payer un programme de fidélité sur mesure — elles utilisent des tampons ou rien du tout."

Les solutions existantes sont soit trop chères, soit trop rigides pour les petits commerces. Nearby leur donne accès à des outils puissants — feed, jeux, récompenses — sans compétences techniques requises, et avec une identité visuelle qui leur ressemble.

Aperçu
La démarche
01

Recherche & conception

Analyse des solutions de fidélité existantes, interviews de commerçants, définition des fonctionnalités core et maquettes UI/UX.

02

Architecture double

App mobile clients (React Native + Expo) + back-office PME (web). API REST Laravel commune, PostgreSQL pour la persistance des données.

03

Développement itératif

Feed, système de points, jeux interactifs, éditeur de parcours de fidélité drag & drop. Cycles courts avec tests utilisateurs réguliers.

04

Déploiement

API sur VPS, builds iOS & Android via EAS Build, site vitrine B2B sur getnearby.tech pour l'acquisition de commerçants partenaires.
